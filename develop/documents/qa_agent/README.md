# 対話／面談AIシステム - バックエンド

## 1. プロダクトの目的
入力されたユーザクエリに回答するためのデータを検索し回答するための自律駆動型エージェントシステム.

※Search MCP: Azure AI SearchやベクトルDBなどと接続して必要データを検索するシステム.


## 2. ディレクトリ構造
AIがファイルを配置する場所を以下の構造とする。

```text
/
├── dialogue_system/   # オーケストレーター(対話システム)
├── qa_agent/          # QAエージェントサーバー
├── search_mcp/        # ベクトルDBなどと接続するMCPサーバー
├── tests/             # バックエンド側の結合テスト
├── ruff.toml          # リンター設定ファイル
└── README.md          # 本ファイル
```
